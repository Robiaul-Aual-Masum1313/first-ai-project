# 🤖 Gemini Quiz AI — Create Dynamic Quizzes Instantly

**Gemini Quiz AI** is an AI-powered quiz application designed to make learning more interactive and engaging. It helps users create dynamic quizzes using artificial intelligence, making it easier to practice topics,
test knowledge, and improve learning through personalized quiz experiences.

🔗 **Live Demo:** [Try Gemini Quiz AI](https://robiaul-aual-masum1313.github.io/first-ai-project/)

**This project was developed entirely with the assistance of AI, primarily using Antigravity.**
---

## 📖 About the Project

Gemini Quiz AI explores how artificial intelligence can simplify quiz creation and support interactive learning.
Instead of relying entirely on manually prepared questions, users can experience an AI-powered approach to generating quizzes.

This project was built to explore AI integration in web development and create a practical learning tool with a simple, user-friendly interface.

## ✨ Features

* **🤖 AI-Powered Quiz Creation** — Create dynamic quizzes with AI assistance.
* **⚡ Instant Quiz Generation** — Generate quiz content without manually writing every question.
* **📚 Interactive Learning** — Practice topics and test your understanding through quizzes.
* **🎯 Dynamic Content** — Explore quiz questions generated based on user input and the application's AI functionality.
* **💡 AI Integration** — Experience the potential of integrating generative AI into a web application.
* **🌐 Live Deployment** — Access the application directly through your browser.

## 🛠️ Technologies Used


* **HTML5** — Application structure.
* **CSS3  — Styling and responsive layouts.
* **JavaScript  — Application logic and interactivity.
* **Google Gemini API** — AI-powered quiz generation
* **GitHub Pages** — Hosting and deployment.
